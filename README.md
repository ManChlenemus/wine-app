Качество вина - Streamlit

Python: 3.13.18.
Для запуска используйте ту же линейку Python: например, для 3.13.18 подходит 3.13.
Версии библиотек указаны в requirements.txt.

Файлы приложения

В одной папке должны лежать app.py, model.joblib, config.json, test.csv,
requirements.txt и README.md. Приложение использует готовую модель и не обучает её заново.

Запуск на компьютере

Распакуйте wine_app.zip и откройте терминал в папке wine_app.
Выполните команды:

python -m pip install -r requirements.txt
python -m streamlit run app.py

Откройте адрес, который появится в терминале.
В приложении можно проверить одно вино, посмотреть метрики и коэффициенты,
загрузить CSV с признаками и скачать прогнозы. is_red: 0 - белое, 1 - красное.
Порог в боковой панели применяется ко всем прогнозам.

Кеширование

st.cache_resource загружает модель один раз и сохраняет общий объект.
st.cache_data сохраняет таблицу и вероятности, возвращая их копии.
При изменении порога вероятности не пересчитываются, меняются только метки и метрики.
Без декоратора joblib.load загружал бы модель заново при каждом действии пользователя.
После замены файлов перезапустите приложение или очистите кеш.

Публикация в Streamlit Community Cloud

1. Загрузите папку wine_app со всеми шестью файлами в GitHub-репозиторий.
2. В Streamlit Community Cloud подключите GitHub и нажмите Create app.
3. Выберите репозиторий, ветку и файл wine_app/app.py.
   Если файлы лежат в корне репозитория, укажите app.py.
4. В Advanced settings выберите линейку Python, указанную в начале README,
   и нажмите Deploy.
5. Проверьте вкладки, изменение порога, загрузку CSV и скачивание прогнозов.
6. Добавьте полученную ссылку в ответ 4.6 и в этот README.
